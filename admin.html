1Koneksi GitHub

Belum terhubung

Perubahan disimpan langsung ke repository GitHub Anda, lalu website diperbarui otomatis oleh GitHub Pages (± 1–2 menit). Token hanya disimpan di browser ini dan hanya dikirim ke api.github.com.

Cara membuat token (sekali saja)
  1. Buka GitHub → foto profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Isi nama (mis. "Admin portofolio") dan masa berlaku (mis. 90 hari).
  3. Repository access: pilih Only select repositories → baricomp4ny.github.io.
  4. Permissions → Repository permissions → Contents: Read and write. Izin lain biarkan.
  5. Klik Generate token, salin, lalu tempel di kolom Token di atas.

Jangan bagikan token ke siapa pun. Jika bocor, hapus di halaman yang sama dan buat yang baru.
